# Рабочий prompt-set — кластер «укрепление склонов»

Свод: операторские (input/prompts.md) + наблюдаемые из блоков выдачи. По этому кластеру
блоков «Обзор ИИ / Похожий вопрос» в выгрузке НЕТ → слой `observed` пуст, работаем от оператора.

| Промпт / ключ | Источник | Интент | P | Citation-target (наш факт → куда на странице) |
|---|---|---|---|---|
| металлическая сеть для укрепления склонов | operator+SERP-head | коммерч. | P1 | высокопрочная стальная сетка → H1 + intro answer-first |
| чем укрепить крутой склон от сползания грунта | operator | коммерч. | P1 | сетка+анкеры вместо бетона → блок «Как это работает» |
| какая сетка лучше для укрепления склона | operator | коммерч. | P1 | высокопрочная сталь ≠ обычная оцинковка → блок «Сравнение» |
| сколько стоит укрепление склона за м² | operator | коммерч. | P1 | 5–50 USD/м², дешевле бетона → блок «Стоимость» (прайс-ориентир) |
| сетка или бетонная подпорная стенка | operator | коммерч. | P2 | дренаж/озеленение/монтаж → таблица сравнения методов |
| кто поставляет системы Geobrugg TECCO в России | operator | коммерч. | P1 | ООО «ГЕОБРУГГ» ОГРН… вся Россия → блок «О поставщике» + NAP |
| укрепление склона вдоль дороги и насыпи | operator | коммерч. | P2 | защита откосов → ссылка ОДМ 218.2.098-2018 |
| защита склона от эрозии/осыпей сеткой | operator | коммерч. | P2 | противоэрозионная сеть → блок «Сферы применения» |
| можно ли озеленить склон под сеткой | operator | инфо | P3 | не мешает дренажу/озеленению → FAQ |
| нужен ли расчёт для укрепления склона | operator | инфо | P3 | проектный расчёт под объект → FAQ + CTA |

**Answer-first правило:** под каждый P1-промпт на странице — извлекаемый абзац-ответ с атрибуцией
бренду в первой трети (не переспам ключей, аудитор флагует). Промпты — прицел, не текст.
