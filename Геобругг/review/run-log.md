## Ограничение окружения (зафиксировано)
Egress-прокси среды блокирует любые внешние домены (403 CONNECT / EGRESS_BLOCKED).
Живой реверс страниц конкурентов и своей страницы через fetch_pages.py / WebFetch **невозможен**.
Первичные источники, на которых построена работа:
- Скриншоты текущей страницы /ukreplenie-sklonov/ (5 шт., предоставлены оператором) — реверс своей страницы;
- SERP-выгрузка serp-ukreplenie-sklonov.xlsx (Яндекс, Топ-20) — заголовки + URL конкурентов (позиционирование);
- input/company.md + выписка ЕГРЮЛ на 20.09.2026 (верифицированные реквизиты);
- input/brand.md (дизайн-система), input/prompts.md (prompt-set).
Следствие для матрицы: триплеты конкурентов помечены источником `serp-title` (по заголовку/URL),
а не полным реверсом тела страницы. Ядро/отстройка выделены консервативно, числа — только
подтверждаемые (со скринов своей страницы / ЕГРЮЛ) либо помечены [to-check].
